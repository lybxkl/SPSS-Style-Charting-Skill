# 出版级图表规范

> 完整的图型目录、SPSS 高级图形对应和默认图表包见 `07-chart-atlas.md`；批量出图用 `scripts/auto_chart_pack.py`。本文件只讲“怎么把一张图做成投稿级”。

## 目标

同一篇论文里的图，应该像同一个人做的：同一宽度、同一字号、同一颜色语义、同一误差线规则。期刊不会因为一张图“好看”接收论文，但会因为图不专业而要求返修。

## 物理规格

| 项目 | 建议值 |
|---|---|
| 物理宽度 | 15.0 cm（A4 正文 15.4 cm 内） |
| 单栏图高度 | 4–9 cm |
| 双面板高度 | 6–8 cm |
| 字体 | 中文宋体（SimSun），西文 Times New Roman |
| 字号 | 轴标签/图例 7.2–8.5 pt；面板字母 9 pt |
| 线宽 | 轴线 0.6 pt；误差线 0.7–0.9 pt |
| 分辨率 | PNG/TIFF 600 dpi |
| 矢量 | PDF，字体 Type 42 嵌入 |
| TIFF 压缩 | LZW，无损 |

配色按下面的推荐结合项目自选，不按软件来源限制。不要用 3D 柱状图，不要在图内加标题。图题和图注在 Word 里排。

## 统一风格

```python
from pubfig import set_style, save_fig

set_style()  # 15 cm, SimSun + Times New Roman, 600 dpi
```

`pubfig.py` 提供：

- `set_style(width_cm=15.0, font_cjk="SimSun", font_latin="Times New Roman")`
- `save_fig(fig, out_dir, name, formats=("png", "pdf", "tiff"))`
- `wilson_ci(k, n)`
- `style_axis(ax, grid_axis="y")`
- `panel_label(ax, "a")`
- `forest_plot(...)`
- `binary_array(...)`：ROC/校准的 0/1 或“是/否”标签编码；未知二值标签直接报错，不猜正类。
- `pie_chart(..., sort=False)`：环形/饼图；有序层级必须关掉按大小排序。
- `qq_plot(...)`、`control_chart(...)`：正态 Q-Q、p 图/X-bar 3σ 控制图。
- `dendrogram_plot(...)`、`classical_mds(...)`、`mds_plot(...)`：层次聚类与经典 MDS，不依赖 sklearn。
- `pr_curve(...)`、`lift_chart(...)`、`confusion_heatmap(...)`：正类较少时的诊断图。
- `kaplan_meier(...)`：无 lifelines 依赖的 KM 曲线，支持删失标记。

`auto_chart_pack.py` 会把 `variable_labels` / `value_labels` 用在轴标签和图注里；`chart_manifest.csv` 的 N 会回写到图注。连续结果自动出“结果分布 + Q-Q + 分组均值+95%CI + 均值趋势”，多分类结果自动出“结果分布 + 组内 100% 堆叠 + 构成趋势”；有 `--coef`/`--pred` 时补森林、ROC、校准、混淆矩阵、PR、Lift；有 `--survival-time/--survival-event` 时补 KM。小样本组（默认 n<10）宁可不画，也不做误导性比较。

## 科研配色推荐（可调整，不是强制模板）

以下是推荐起点，不是统一的“SCI 色号标准”，也不是交付必选项。Agent 可按数据含义、领域惯例、期刊要求、用户偏好和实际图幅自行选色、换色、扩展色板或使用单色；不要求固定色号、固定色板、固定类别数量，也不要求每张图都彩色。用户/目标期刊有具体要求时按实际要求处理，不为迁就示例色卡改变数据或删掉类别。

### 按数据含义选方案

| 情况 | 可考虑的方案 | 选择时关注 |
|---|---|---|
| 单组频数、发生率或一条趋势 | 单色 + 位置/长度/线型 | 颜色是否确实提供信息，不必逐项染色 |
| 无序类别、多个组别 | 离散分类色板 | 区分组别，避免无依据暗示高低、好坏 |
| 有序等级或从低到高的连续值 | 明暗有序的顺序色板 | 感知顺序与数值顺序一致；缺失不混作低值 |
| 相关、增减、相对基准的偏离 | 以有意义基准为中心的发散色板 | 标明基准（例如相关的 0），色标与数据尺度匹配 |
| 相位、方向等首尾相接的量 | 首尾平滑的循环色板 | 避免人为制造周期边界；需要时仍可用其他标记表达 |

这些是常见选择，不限制其他合理设计。连续量一般不宜直接套无序分类色环；彩虹色可能制造不均匀的视觉分界，确需使用时检查它与数据/领域惯例是否匹配，不把“禁止某个色板名称”写成通用规则。

### 可直接使用的起点

当前 `pubfig.py` 提供 8 色分类默认值；它是便捷的回退方案，**不是唯一允许的色环，也不是最多只能画 8 个系列**。例如两个类别可从深蓝 `#1C4E7B` 与橙色 `#E18560` 开始，第三类可考虑灰绿 `#4B6E52`，辅助内容可考虑灰色；这些色号都可替换，不规定“处理组必须蓝、对照组必须橙”，也不赋予颜色普遍的正负价值。

自动图包的 `config.palette` 可给一个颜色或一组颜色，实际用于多组分类堆叠、环形、MDS、KM 等绘图；同一变量的分类色按完整数据保持映射，子图只显示部分水平时也保留其颜色。单色主结果、参照线和连续色标仍按各自绘图调用控制，不承诺用分类色环替换所有视觉元素。自定义图可给支持的绘图函数传 `color` / `colors` / `cmap`，或由 Agent 自编绘图脚本。若某个自动入口没有暴露所需颜色配置，换实现或显式给绘图调用传参；不能只改 manifest 就声称图里已经改色。类别多时可扩展色板，结合线型、点形、纹理、直接标签或同图分面；不因默认色板长度减少数据集、模型、系列或类别，图的分页仍遵循用户选择。

### 推荐的复核方式

- 同一语义跨图尽量保持相同颜色和图例；不同图有意变换尺度或映射时作出说明。无序类别本身不必靠明暗暗示排序。
- 尽量避免只靠颜色传递关键区别，可叠加点形、线型、纹理或直接标注。红/绿并非一概禁用，检查实际色觉模拟与辅助编码后再决定。
- 看实际安置尺寸与背景：淡色细线、浅灰点可能难读，过深区域中的黑字也可能消失；别只看独立色卡。比较相同指标的面板可考虑共同色标范围，不同范围则明确标注。
- 根据用途查看彩色、灰度与色觉模拟；模拟和色差只是诊断，不能单独证明整图可读，也不应机械推翻靠线型/标签已能清楚区分的方案。
- 以原始数据和研究意义决定颜色映射，不通过不同面板任意改色标范围来放大差异，不把缺失值伪装成真实 0。

### 代码检查的适用边界

`qa_outputs.py` 默认将分类色板的低灰度间隔记为 **warning，返回成功而非拦截**；`ΔL*≥10` 是内部建议阈值，不是普遍期刊标准。色觉相似提示使用模拟后的完整 Lab 色差，而不是只因色相接近就报警；黑白/灰阶仍可能凭明度清楚区分。建议项不要求全部清零：结合实际图、线型/标签等评估后，可以保留适合项目的原方案并简要说明，不因一个阈值提示强制换色或返工。`--colorblind` 可加色觉模拟提示；不需要灰度诊断时可 `--no-graycheck`。只有用户/期刊实际要求这条分类色灰度规则时，才显式选 `--strict-palette` 将低间隔升级为 error；显式严格检查遇到无法解析的分类颜色时，也不能以“已核查”放行。透明度/背景未纳入孤立 RGB 色差模型，遇到透明颜色记录未完成并回到实际渲染检查；它不是默认终检必选项。真实数据、来源、文件完整性、N 和已经明确的版面要求仍按各自规则核验，不受配色建议放宽影响。

`paper_figures` 的每张图规格可给 `palette_kind`；自动图包的 save(extra=...) 也可逐图记录并保留到 CSV，config 中的同名默认值可被逐图覆盖。未声明时从真实艺术对象区分离散颜色、单色、连续映射或原生 RGB 图片，不一概填成分类色板。混合/自定义图仍可声明自己的用途，推断并不替代研究语义判断。

manifest 的 `palette` 记录可提取的真实数据图元颜色（含边线/置信区间，可能含透明度），`palette_source` 说明取色和用途来源；`colormaps` 单独记录实际使用的标量色图名称。连续映射不会被展开成成百上千个“类别色”，RGB 图片也不冒充使用了默认色图。没有提取到离散色时留空，不拿默认 8 色伪装成实际取色。这些元数据不能单独证明图像语义或可访问性，连续色标的单位、范围/归一化和图例仍须实际核对。

QA 兼容缺少用途的旧清单时按 categorical 诊断，并说明假设。分类颜色才应用两两色差启发式；连续/循环/单色/自定义映射可以保留自己的方案，不套该门槛。报告 `pairwise_checked` 表示确实算过有效颜色对，`complete` 仅表示本项声明颜色的诊断输入完整；未解析、透明、仅推测默认色环或不适用该方法的项目均不能称为整图已验证。`palette_unchecked` 按本次可检查的有效图统计，审稿包也保留这个范围；它不是强制改色或“数据错误”的计数。

命名颜色包含空格时，清单优先使用 `|`/`;` 分隔，例如 `xkcd:sky blue|#D55E00`。`white`、`#fff`、`#FFFFFF` 是同一实际颜色，不算成三个独立类别色。非法颜色与非法系列数会明确留诊断，不静默截断或漏核；这不限制合法色板的形式/长度。

MDS/KM 不再按“前 6 组”静默省略分类；MDS 图幅覆盖实际坐标范围。KM 以有效观察逐组显示并标各组 n，小组仅支持相应描述，不能据此夸大推断；Agent 仍按研究设计评估样本充足性，不靠删组凑出外观。

若项目使用图内/面板标题，`save_fig` 会在斜标签调整之后测量顶部图例与轴标题，给两者分开留白；这不替代对超长图例、跨面板元素和实际安置尺寸的目视复核。

可参考的公开资料（是选型依据，不将其示例固化成必选色卡）：[ColorBrewer 的顺序/发散/分类说明](https://colorbrewer2.org/learnmore/schemes_full.html)、[Elsevier 的可访问图形建议](https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions)。

## 常见图型

### 比例 + 95% CI

- 点估计用实心点，误差线用 95% Wilson CI。
- 不要用柱状图叠误差线代替点图；柱高会误导读者把面积当比例。
- 在 n<30 的组旁标注样本量，或直接不画。

### 森林图

- OR 用对数轴；参考线 OR=1。
- 实心点 = 95%CI 不含 1；空心点 = 不显著。
- 左侧放变量标签，右侧放 OR（95%CI）文本。
- 参照组不画点，在表注说明。

### 趋势图

- 年度点估计 + 95%CI；样本量 <30 的年份不单独下结论。
- 不要用平滑曲线掩盖年度波动；需要平滑时说明方法与带宽。
- 横轴年份按等距，不按样本量。

### 交互图

- 纵轴为预测概率或组内均值，注明是哪一个。
- 两条线分别代表调节变量的两个水平；误差线为 95%CI。
- 图注写清交互模型 N、参照组、控制变量。

### 对应分析

- 只作为探索性工具，不单独据此下结论。
- 图注写清纳入的阶段/类别、排除的类别、维度解释率。
- 不要把维度 1/2 擅自命名，除非有外部验证。

## 图注模板

```text
图 2  处理阶段与结果发生率（N=1,200）
注：点为阶段内结果发生率，误差线为 95% Wilson CI；样本为研究期内的
研究资料；阶段按资料时点可查证的最高处理事实编码；“结果”指资料中
明确记载的处理结论。数据来源：研究资料库。示例数值为虚构。
```

图注四要素：

1. 图号 + 标题（标题说“是什么”，不说“结论是什么”）。
2. N 与样本范围。
3. 点/线/误差线/颜色的定义。
4. 数据来源与必要的编码说明。

## 导出

```python
fig.savefig(f"{out}/{name}.png", dpi=600, facecolor="white")
fig.savefig(f"{out}/{name}.pdf", facecolor="white")  # 字体嵌入
fig.savefig(f"{out}/{name}.tiff", dpi=600, facecolor="white",
            pil_kwargs={"compression": "tiff_lzw"})
```

投稿优先级：

1. 单图矢量 PDF（字体已嵌入）。
2. 期刊要求位图时用 600 dpi TIFF。
3. PNG 用于 Word 内嵌和预览。
4. 合并 PDF 只用于预览，不要直接投稿。

## 导出后检查

- PDF 打开后放大 400%，文字不模糊、不出锯齿。
- 中文没有变成方框；负号显示正常。**缺中文字体时脚本会直接报错并列出本机候选**（`set_style` 先验字体，只有候选为空才崩）——图里出现方框说明你绕过脚本手写了 matplotlib 调用，或者把 `findfont` 警告过滤掉了。
- 图宽 15 cm 时，最小字号 ≥7 pt。**终稿必须跑 `qa_outputs.py --min-fontsize 7.2`**：不带这个参数只查分辨率，字号闸门是关着的；成稿 PDF 里嵌的是位图时，字号无法从位图核（严格检查需要匹配的原始矢量图及 DOCX 实际安置宽高；缺少证明计 error，不能把 warning 当严格通过），但图框内**没有文字层且分辨率不达标**仍是 error。
- 配色按实际数据和用途选择，可查看灰度/色觉模拟并结合线型、点形、纹理或标签。8 色默认值、内部色差阈值都是推荐；系列更多可扩展或换方案，不按类别数或色号拦截。
- 图注中的 N 与数据、表、正文一致。
- 每张图都有独立源文件，不依赖 Word 截图。
- **对数轴的次刻度标签必须关掉**：`forest_plot` 只设置了主刻度格式器，次刻度仍是 `LogFormatterSciNotation`，会渲染出 `3×10⁻¹ 6×10⁻¹` 与 `0.1 1 10` 混排。修法不是清空 locator（那会让主刻度只剩下 1–2 个点），而是关掉次刻度**标注**并显式给主刻度：

```python
from matplotlib.ticker import NullFormatter, FuncFormatter

ax.xaxis.set_minor_formatter(NullFormatter())
ax.tick_params(axis="x", which="minor", length=0)
ax.set_xticks([0.1, 1, 10, 100])
ax.xaxis.set_major_formatter(FuncFormatter(lambda v, p: f"{v:g}"))
```

- **不要用 `bbox_inches="tight"` 补留白**。它会把画布裁掉：15 cm 宽的图从 885 px 变成 724 px，600 dpi 下从 3543 px 掉到 2899 px，若仍按 15 cm 排入文稿，有效 dpi 会降至约 491；不能用裁边后的 DPI 元数据冒充版面分辨率。要留白就用 `fig.subplots_adjust(top=0.86)` 或给整图加 `constrained_layout`，宽度保持不变。
- 轴外图例是有条件的风险：`stacked_bar`/`stacked_area` 把图例放在 `bbox_to_anchor=(0.5, 1.16)`，默认 `top=0.88` 时余量约 −26 px（已经压边）；`top=0.92/0.95/0.99` 分别溢出 40/91/158 px。要么把 `top` 压到 0.80 以下，要么改用轴内图例。

## Word 导 PDF 的陷阱

Word 导 PDF 时会把嵌入图重采样到约 200 dpi（600 dpi 的 3543×1590 会变成 1180×529）。文件看起来正常，但印刷会糊。解决：

1. Word 里保留 600 dpi PNG。
2. 导出 PDF 后用 `export_pdf_hires.py` 按图题定位并回填原图。图题 tag 有数字边界，`图1` 不会匹配 `图10`；优先匹配行首图题，避免被正文“见图1”带偏。
3. **回填后必须清内容流**，否则旧位图留在 `/Resources`：`page.replace_image(xref, filename=png)` 后接 `page.clean_contents(sanitize=True)`，最后 `doc.save(out, garbage=4, deflate=True)`。实测不清会从 4 张图变 8 张、体积 10.5 MB 涨到 21.1 MB。
4. 用**有效 dpi** 检查（像素宽 ÷ 版面英寸），不要用像素宽：15 cm 宽时 3000 px 只有 508 dpi，3543 px 才是 600 dpi。`qa_outputs.py --min-dpi 600` 按此判定，并按图幅过滤 logo/公式碎片（`rect_w_pt ≥ 56.7` 或面积 ≥ 200 000）。

不要用“另存为 PDF”后直接投稿，除非已验证内嵌图分辨率。

## 多类别与长标签：同图倾斜

默认不将图分页。保留所有类别与完整标签，发生重叠时先倾斜 45°，必要时 60°/75° 并增加底部留白，不以缩小字号解决。`pubfig.save_fig()` 与 `compose_figure()` 在导出前用实际 renderer 测量刻度文字，按旋转矩形检查相交（斜标签的轴对齐外框相交不代表文字重叠），同时检查画布裁切。自动图包将修正角度记录在 JSON 的 `tick_layout` 中。`binary_prevalence` 保留全 0/全 1 合法变量及 Wilson 区间，拒绝非 0/1 输入，不对比例求和后强转整数。

若 45°/60°/75° 在目标图宽仍放不下，导出报错并保留完整变量清单，不输出假成功图、不截掉项目、不自动分页。Agent 应调整图幅/纸幅或同图分面；图在 Word 中缩小后仍须通过实际字号检查。该检测覆盖主刻度同轴文字与画布边界，不能替代对值标签、图例、跨面板重叠和最终文档的渲染复核。
