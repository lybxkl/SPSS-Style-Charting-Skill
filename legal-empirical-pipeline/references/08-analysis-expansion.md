# 分析扩展清单：不要只跑一个主模型

用户给的数据通常足够支撑一组“主分析 + 描述 + 异质性 + 稳健性 + 诊断”的组合。默认把能做的都做一遍，再把不支持的写明原因；不要等用户反复追问“还能不能再看点什么”。

先跑自动筛查：

```bash
python scripts/auto_stats.py --data data/analysis.csv   --config assets/chart_config.example.json --out output/analysis_pack
```

它给出描述统计、组间检验、相关、单变量模型和 `univariate_skipped.csv`，帮你快速判断哪些变量值得进入多变量模型。再配合 `auto_chart_pack.py` 看分布、异质性和时间趋势。自动筛查是探索性的，最终模型必须按分析计划在 SPSS 中估计，不能按 p 值筛变量。

结果变量类型由脚本自动判断，不要强行套二元模板：

| 结果类型 | 自动处理 | 图形 | 注意 |
|---|---|---|---|
| 0/1 | Logistic OR、组间率+Wilson CI | 结果分布、组率、趋势 | 事件数 <10 会警告 |
| 连续 | OLS β、均值+95%CI、Pearson/ Kruskal | 直方图、分组均值、均值趋势 | 偏态做 log/P99 并注明 |
| 多分类结果 | 卡方/Cramér's V、Kruskal；二分类单变量模型跳过 | 构成条形、组内 100% 堆叠、构成趋势 | 不把类别编码当连续值；改用多项 Logit |
| 多分类自变量 | 自动哑变量化后进入单变量 OLS/Logit（`变量_水平`） | 类别构成、分组比较 | 参照组为省略的水平；高基数变量先合并 |
| “是/否”文本 | 常见标签自动映射；其他用 `outcome_map` | 同二元 | 脚本不猜正类方向 |

完全分离、空 2×2 单元格、估计不稳定的单变量模型会写入 `univariate_skipped.csv`；不要把这些“巨大 OR”写进正文。过滤后 0 行、结果列全缺失、`filter_query` 写错时脚本直接报错退出。

## 0. 原则

- **先预设，后看结果。** 主模型、核心变量、参照组在看结果前定好；扩展分析可以探索，但必须标注“探索性”。
- **报告全部，不挑显著。** 跑过的模型/图都进清单；不要只留下 p<0.05 的。
- **效应量优先。** 除了 p，报告 OR/β、95%CI、边际效应、预测概率。
- **每个扩展都写“回答什么问题”。** 没有问题就不做。
- **数据不支持就跳过并记录原因。** 不要用假数据凑图。

## 1. 数据质量

- [ ] 样本流程图：原始文件→可读→范围→去重→分析。
- [ ] 缺失率：变量级条形图；关键变量缺失是否与结果相关。
- [ ] 异常值：连续变量箱线/散点；是否截断/缩尾。
- [ ] 重复：MD5/案号；重复率与去重后 N。
- [ ] 年份/地区/类别覆盖：是否存在空档、极端集中。
- [ ] 编码一致性：κ/一致率；分歧案例。

## 2. 描述统计

- [ ] 核心结果总发生率 + 95%CI。
- [ ] 核心自变量各层级 N、占比。
- [ ] 因变量×核心自变量交叉表（行%/列%）。
- [ ] 主要类别×结果率 + 95%CI。
- [ ] 连续变量分布（直方图+箱线；偏态用 log/截断）。
- [ ] 年份趋势：样本量、结果率、构成。
- [ ] 地区/审级差异：结果率+CI。

## 3. 双变量

- [ ] 分类×分类：堆叠柱/热图/对应分析。
- [ ] 分类×连续：提琴/箱线+散点；均值差+CI。
- [ ] 连续×连续：散点+拟合、相关热图、偏相关。
- [ ] 二元×二元：2×2 表、OR/RR+CI。
- [ ] 关键变量与结果的关系是否单调/非线性；必要时加二次项/分段。

## 4. 多变量

- [ ] 主模型：因变量、参照组、核心自变量、控制变量。
- [ ] 逐步加控制：模型 1 基础、模型 2 + 程序性变量、模型 3 + 固定效应。
- [ ] 类别/地区/年份固定效应或哑变量。
- [ ] 交互：调节变量×阶段、地区×阶段、年份×阶段。
- [ ] 分组模型：分类别/分地区/分审级。
- [ ] 替代因变量：连续/有序/二元版本。
- [ ] 替代样本：去重前后、排除极端年份、仅一审。
- [ ] 替代编码：层级合并/拆分、不同参照组。
- [ ] 模型比较：AIC/BIC、拟合优度、解释力。

## 5. 模型诊断

- [ ] 完全分离/稀疏单元格：OR 是否爆炸；是否需要 Firth。
- [ ] 多重共线性：VIF/相关矩阵。
- [ ] 影响点：Cook's distance/dfbeta（线性）或预测概率异常。
- [ ] 校准：预测概率 vs 实际率。
- [ ] 区分度：ROC/AUC（如做预测）。
- [ ] 拟合：Hosmer-Lemeshow 或校准斜率。
- [ ] 聚类/稳健标准误：法院/地区层面。
- [ ] 缺失机制：完整案例 vs 多重插补敏感性。

## 6. 异质性

- [ ] 分类别：核心系数森林图。
- [ ] 分地区：东部/中部/西部/东北。
- [ ] 分审级：一审/二审。
- [ ] 分年份：早期/中期/晚期。
- [ ] 分调节变量水平：高/低或分组。
- [ ] 交互模型 + 分组预测值。
- [ ] 亚组样本量是否足够；小样本组只描述不推断。

## 7. 机制与解释

- [ ] 中介分析（只有理论+时序支持时才做；否则只写“可能机制”）。
- [ ] 边际效应：在代表性取值上的预测概率。
- [ ] 交互图：不同调节水平下阶段→结果的预测概率。
- [ ] 剂量反应：阶段/金额/时长的连续化。
- [ ] 文本机制：裁判理由中的关键词/证据句分布。
- [ ] 竞争解释：程序性/实体性控制变量是否解释掉核心系数。

## 8. 预测与分类（如适用）

- [ ] 训练/验证划分或交叉验证。
- [ ] ROC/AUC + 95%CI。
- [ ] PR 曲线 + AP（正类较少时优先于 ROC）。
- [ ] 校准曲线 + Brier score。
- [ ] 混淆矩阵/阈值表。
- [ ] 十分位 Lift/增益表。
- [ ] 变量重要性/系数森林。
- [ ] 决策曲线（如临床/政策场景）。
- [ ] 有随访时间/事件列时：Kaplan–Meier + Cox（检查 PH 假设）；没有就写明跳过。

## 9. 降维与聚类（探索）

- [ ] 相关热图 + Bartlett/KMO（因子适用性）。
- [ ] 碎石图 + 平行分析。
- [ ] PCA/因子载荷 + 双标图。
- [ ] 系统聚类树状图 + 轮廓系数。
- [ ] 对应分析/MDS（类别变量）。
- [ ] 明确标注“探索性”，不据此下因果结论。

## 10. 文本与编码

- [ ] 关键词年度热度。
- [ ] 编码类别共现矩阵/热图。
- [ ] 证据句类型分布。
- [ ] 代表性案例表（不是图）。
- [ ] 主题模型/词云只作辅助，不替代人工编码。

## 11. 交付前的“分析清单”

在 `analysis_manifest.md` 里列：

| 分析 | 问题 | 样本 | N | 图/表 | 状态 | 备注 |
|---|---|---|---|---:|---|---|
| 主模型 1a | 阶段→结果 | 阶段 2–5 | 1,000 | 表 5/图 5 | 完成 | 控制类别/地区/年份 |
| 稳健性 1 | 去重后重跑 | 唯一样本 | 980 | 附表 2 | 完成 | 结论方向一致 |
| 交互模型 | 调节变量 | 阶段 2–4 | 880 | 表 7/图 6 | 完成 | 探索性 |
| 生存分析 | 履行/再犯时间 | 有随访列 | 按列缺失 | KM 图/附表 | 有则做 | Cox 在 SPSS/lifelines，检查 PH；无随访列写明跳过 |

这张表就是“为什么没做/做了什么”的答案，能显著减少用户反复追问。

## 12. 不要做的事

- 不要跑 20 个模型只报 1 个显著的。
- 不要用 p 值筛选变量后再解释。
- 不要把探索性 PCA/CA/聚类写成验证性结论。
- 不要在没有时序/理论时做中介。
- 不要用预测模型代替因果模型。
- 不要为了图多而重复画同一信息；每张图要有独立问题。
