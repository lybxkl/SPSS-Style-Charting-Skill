# 2026-11-14 配色、展示完整性与检查语义审计

本轮针对上一轮“配色作为推荐方案”的改动，沿源码检查配置 → 绘图对象 → 清单 → QA → 审稿包 → 安装包，同时复核多组图的组别、样本量和显示范围。发现的问题已修复；配色默认仍给建议，不限定色号、色板、模型、数据集或类别数。此前资料/统计/论文交付的审计见 [2026-11-13 报告](AUDIT-2026-11-13.md)，本报告不取代历史记录。

## 发现与处理

| 编号 | 原问题及影响 | 修复与证据 |
|---|---|---|
| C01 | 色觉提示只看色度分量，黑白因同色相被误报难以区分。 | 使用模拟后的完整 Lab 色差判断；黑白高明度差反例不再报警。模拟仅提供建议。 |
| C02 | `min_delta_e` 参数未实际控制提示阈值。 | 参数参与比较；0 与 100 阈值反例产生不同结果；非有限/负阈值拒绝静默接受。 |
| C03 | 含非法颜色时仍可能声称两两检查已完成、严格检查已应用。 | 解析数、无法解析颜色、实际计算和输入完整性分别记录；显式严格分类检查遇到无法解析颜色给错误。默认诊断仍为建议。 |
| C04 | 有透明度的颜色被当成完整不透明色核查。 | 记录 `alpha_unassessed` 和未完成；孤立 RGB 距离不冒充已考虑背景的渲染验证，也不强迫更换合法透明色。 |
| C05 | `white` / `#fff` / `#FFFFFF` 被当作三个独立色；带空格的命名色被拆碎。 | 按实际 RGBA 去重；明确的 `\|` / `;` 分隔符保留命名色，兼容旧逗号/空白形式。 |
| C06 | 只启用色觉诊断、没有显式色板或只有一色时，未核范围可能消失。 | 每个适用清单行留下诊断；假定默认色环、单色、连续/自定义等范围明确标未由分类色方法完成。 |
| C07 | `n_series=inf/NaN` 可能异常，小数可能静默截断。 | 检查有限、非负整数；非法值提示并保持未知，不伪造系列数。 |
| C08 | 自动图包的 `config.palette` 仅进清单，部分实际图仍用默认色。 | 将配置实际传给多组堆叠/环形/面积/MDS/KM；同变量按完整数据保持子集颜色。独立检查真实柱面颜色与清单，而非只比配置。非法配置 CLI 明确返回 2。 |
| C09 | NumPy RGBA 数组、短色名、黑白或透明度可能漏收；隐藏图元可能混入。 | 按真实可见数据图元收集 RGBA；保留边线、参考线、CI 等可提取颜色，排除隐藏/全透明元素。清单颜色不等同于语义系列数。 |
| C10 | 没有提取到颜色时填默认 8 色；连续映射可能被误当离散类别色。 | 无离散色则留空；单独记录实际标量 `colormaps`，用途声明/推断来源进入清单。原生 RGB 图片不冒充使用默认色图。自动图包与论文图入口保持一致。 |
| C11 | MDS/KM 内部只画前 6 组，未明确展示全部有效组。 | 移除隐藏上限；9 组反例检查每组/每条曲线，保留全部有效观察。类别多时由 Agent 设计辅助编码和布局。 |
| C12 | MDS 以 1%–99% 分位数定范围，极端点可能在画布之外。 | 按实际最小/最大坐标加留白；反例核对 36 个点和坐标 10000 的点均纳入显示范围。 |
| C13 | KM 小于 3 条观察的组不显示，但清单 N 仍可能包含它们。 | 有效组保留，图例标每组 n；1/2/4 条观察的反例核对三条曲线总 n=7。低样本曲线仅作相应描述，不能推断其研究设计足够。 |
| C14 | 审稿包未转发配色未核范围，容易只看到零错误。 | 保留 `palette_unchecked/palette_eligible` 并解释为方法覆盖范围，不当成数据错误或强制改色数。 |
| C15 | 实际渲染中，9 类顶部图例完整却与图标题重叠；原测试未覆盖。 | 最终导出在斜标签调整后测量标题/顶部图例，分开并预留画布。测量反例及 PNG 目视复核确认 9 项完整、标题间距 3 pt，未分页、缩字或删项。 |
| C16 | 程序化调用图包时，部分入口直到保存才设置字体，已创建的首图文字仍可能沿用旧字号/字体。 | 图包初始化时设置尚未初始化的样式；用户已设定的项目样式不覆盖。补测初始化时点和自选字号保留，重跑合成渲染。 |
| C17 | 新增布局预渲染可能缓存文字，造成最终保存不再重发缺字警告，原有“中文方框必须报错”回归因此失败。 | 捕获布局阶段与写图阶段的缺字警告，两阶段均不能静默放行；保留原有独立缺字反例，修复后重新验证。未以删除失败测试处理。 |
| C18 | 折线的点形填充/边线可与线条分别着色，只取线色会漏记。 | 收集实际启用的点形面色/边色；无点形时不收其未使用的点色。蓝线/红点/黑边反例检查三色均进入元数据。 |

主要源码：`qa_outputs.py`、`pubfig.py`、`auto_chart_pack.py`、`paper_figures.py`、`review_pack.py`。README、科研配色说明、图谱、QA 清单、规格模板与契约同步说明推荐性质、实际取色和未核语义。

## 覆盖边界

本轮没有读取或改写真实研究资料，没有生成新的实证论文，也没有验证所有学科模型。全量代码回归包括既有数据/统计/论文交付用例，不能据此声称语义正确性、所有未来输入或所有布局已获证明。真实项目仍须全格回源复读、逐模型数据/设计评估、数字一致性检查和最终 DOCX/PDF 渲染复核。

色差阈值是内部启发式建议，不是通用期刊标准；只有显式 `--strict-palette` 才启用额外严格分类色规则。`pairwise_checked` 表示算过有效颜色对，`complete` 仅表示该项声明颜色诊断输入完整。固定矩阵仅模拟两类色觉条件，不能覆盖所有视觉条件；透明度/背景、连续范围/归一化、图片、混合编码、标签与缩放后的整图可读性仍需实际检查。不得把零错误或单项 complete 写成整图“已证明可访问”。

当前修复更新仓库及 `dist` 安装包；未擅自同步其他安装目录、旧备份或第三方插件。旧项目必须在修复版重新生成图/清单并运行 QA，不能仅改旧报告中的状态。
