# 当前 v2 维护与交付流程

本文只在验收档 archive 使用。explore 与 submission 不要按本文补做逐格第二遍复读。可投稿档的复核是抽样记录，不是本文的 final。

本文补充 references/12 和 references/13，以当前脚本的 `--help` 和契约 schema 为字段依据。v1 命令继续可用；v2 的正式发布必须消费当前 v2 证据，不能通过省略 v2 字段把旧回执当成新验证。

## 从材料到整表复核

1. 冻结原件，建立物理文件清单、逻辑单元、恢复范围和字段/数据集候选。DOCX 的脚注、尾注、批注、页眉页脚单独定位；压缩包同名成员保留独立序号。未解析成员和未恢复区域必须继续处理或说明具体原因。
2. CSV 审计视图用于逐格定位，不要求原生数据或模型输入只有二维表。`audit_view.build_view` 支持自选 `file.py:builder` 与独立 `file.py:checker`，校核形状、轴、顺序、类型、精确值与嵌套路径；哈希相等不能证明没有丢字段。大整数不得先转 float。近似读数、插补、估计与模拟保留原始层、方法和不确定性，不能标成直接观测。
3. 数据整合和 provenance 完成后，调用 `review_workbench` 导出。所有数据集共用当前 `verification_snapshot.json`；导出的签名来自 `verify_dataset.Verifier.prepare`，值指纹只用于补丁并发控制，不能充当复核签名。
4. `blind_template` 隐去首遍值。Agent 或复核者必须在 prepare 后**实际重开原件**，逐格读定位、上下文、实体、时间、单位、缺失与派生输入，再填写第二遍值、实际时间、身份和具体复核说明。模板不能复制首遍值后自动签字。编码映射与派生公式须独立重算。
5. `import_second_pass` 原子写入事件；冲突保持 disputed，裁决后重新复核。`write_review_file` 写出后再执行 `verify_dataset --stage final`。所有数据集的主键、空格、空值、标记、编码、派生格都在范围内。合法空表以真实范围证据处理，不计算 0/0 的核对率。
6. 数据、原件、转换代码、证据账本或复核事件变化使旧 final 失效。图表或文稿数字必须绑定重新通过的版本。源图/音频的复读事件是 source-unit 事件，不冒充数据集单元格事件。

同格出现新的差异或争议后，旧 verified 行不能覆盖新事件；final 要求最新第二遍明确确认当前值。事件按解析后的真实时间排序，不能按 ISO 字符串字面比较 `+08:00` 与 UTC。历史上已删除的键仍留账，当前工作台只统计现存目标。

脚本可以核对版本、定位和值是否一致，无法证明复核者真的理解了全部上下文。逐格真实复读是 Agent 的工作，回执字段本身不是语义真值。

文本恢复严格解码：自动识别 BOM 或 UTF-8，其他编码先确认，再用 `source_units build --encodings encodings.json` 提供“材料相对路径 → 编码”映射。不用替换字符掩盖失败。恢复表示按内容寻址保留历史；活跃单元按当前原件哈希与 materials.json 代次选择。更新恢复/发现实现后重跑，旧覆盖记录不能沿用。同名字段按来源和出现位置分别保留；相同发现重跑保留已完成处置，来源内容改变则重评。

PPTX 可保留原生正文、表格、备注及媒体/嵌入对象；原生 XML 不能证明幻灯片视觉信息已读全。OCR/ASR 子区域已复读，也不自动代表整页/整段完整。实际完成整体审查后写具体范围报告，再调用 `SourceUnits.review_scope(..., report=..., reviewer=..., note=..., remaining=[...])`。报告记录恢复子单元、未解区域和排除理由；空列表只用于已实际解决的范围。报告改变、包含资料无当前单元或仍有未恢复范围时，完整交付不放行。此范围审查与整合后逐格复核分别完成。

## 发现与补数闭环

搜索不截断被索引的长文本，展示的命中条数上限不等于扫描范围。回执记录实际来源过滤、扫描单元、原件清单和索引哈希；新增、删除、修改材料或改索引后，旧回执不能证明当前覆盖。关键词未命中不能推出资料中没有该字段，应换同义词、表格、脚注、附件、实体、时间与相关上下文继续找。

`found` 只是线索。`gaps resolve` 必须指定已实际写入的数据集格子和当前全表 final；格子的来源必须对应实际找到的来源。模型缺数还须在补表复核后重评该模型。未找到时保留真实搜索范围与理由，不填 0。open/searching 或过时的关闭依据会阻止完整发布。

blocked 也是未完成。重新搜索可以替代已失效的旧搜索依据，旧记录仍保留；不能因为历史中有一份过期回执就使新的有效回查永远无法关闭。索引同时绑定当前原件、实际恢复文本及恢复修订；修改中间表示或重新校正 OCR 后也要重建。

## 开放模型与独立校核

模型族、输入角色、数量和结果类型不设白名单上限。内置实现是便捷入口，其他方法选择 Python callable 或外部命令执行器。不能把“可以接适配器”写成“已验证所有引擎”。

- Python `runner(project, spec)` 返回结构化结果；或配置 `executor.command`（参数数组）、`result`（新生成 JSON）、`code`、`timeout_seconds`。支持曲线、矩阵、轨迹、预测等 payload，保留原生输出哈希。
- 原生非表格输入可通过 `conditions_runner="file.py:function"` 真正读取并检查条件；返回具名布尔检查和具体依据。CSV/TSV 内置读取保留前导零等身份字符串，只转换真正参与计算的变量。`ready` 是配置状态，不能代替条件、估计、校核和发布状态。
- 执行绑定输入、实现代码、解释器和相关包版本，并保护原件；运行中输入/代码改变即失败。原生输出不得复用未更新的旧文件。拟合成功只代表执行完成。
- 拟合、训练、校准、约束、参数、初值、边界、验证和测试的文件分别记录版本、键和角色，不跨表累加独立 N。内置估计器只直接消费一份拟合表；权重/offset 或多份拟合表应选实际支持这些语义的适配器，内置入口明确报错，绝不默默忽略。统计 N 取实际使用键；`n_dropna` 只表示因缺失剔除的行数。
- 内置 OLS/Logit 等、MixedLM、GEE、聚类稳健协方差各记录实际诊断。小样本警告不充当全方法一刀切的禁止条件；不收敛、秩亏、分离、设计与识别缺口不能用空字典或 False 充作已满足。
- LP 与 MILP 分别求解，MILP 必须声明整数域。非线性方法必须支持所给边界/约束，并重新检查可行性。局部解、小残差、可行轨迹不升级为全局最优；ODE 产物是轨迹。无统计 N 的数学模型记录维度与约束，不编造 N。
- `validation.independent_ols/independent_logit` 只校验相应无权重模型的数值层。其他实现使用独立 `validator(project, spec)`、比较字段与预设容差。共享抽取或预处理必须单列，数值一致不证明原始抽取正确。IRLS 未收敛不能产生通过记录。重新拟合、数据/代码/环境改变后旧校核无效。
- 校核回执列明字段范围和实际 N。内置系数校核通过不能替标准误、区间、p 值或预测背书；展示这些字段前补充对应独立校核。任意参数名使用 JSON Pointer，例如 `/coefficients/x.dot/estimate`，常用点路径继续支持。零容差比较保持大整数精度。多重比较不消费未经校核的 p 值。
- 原始 beta、OR、IRR、边际效应和标准化参数分别记录；内置原始系数不能只改标签冒充变换。自选适配器实际完成所需变换，保留原生尺度用于可比性判断。所有方法继续开放。
- 稳定性保留每项请求，包括失败、不可用、不适用和未执行；零个实际变体不能 passed。聚类、滞后等要有实际数据和真正执行的规格。多重比较保留完整检验族及选择理由；预测按组/时间留出，预处理只用训练集。`compare_results` 对目标、尺度、单位、分母、组、观察窗不一致明确报告，不能直接比较显著性。

## 结论、图与完整文稿

`claims.check` 是机械筛查，会检查方向、极值、数字、口径、时间和因果表述；它不替代语境判断。正式论断还需 `claims review`：实际重新阅读支持来源，提供具体定位、源 SHA、身份和评估说明。`support_review` 将这次判断绑定论断文本、范围及当前支持版本；改结果、文献或原件后重新复核。不能用审阅声明覆盖机器已发现的矛盾。

文献分别记录 DOI 身份、实际获取的 metadata/abstract/full_text、逐句原文支持，以及真实检查过的撤稿/更正来源与范围。未在某个已检查来源报告撤稿不等于证明全网没有撤稿。换文章身份不能继承旧全文与支持。

图先核实际图元与数据，再核交付 PNG 是否确实来自这张图。多类别中文标签优先斜放并增大图幅/底部留白；同图保留全部文本与字号，不自动分页或丢系列。配色用途与色觉建议只推荐；连续色图、透明度、点形和边色按实际用途报告。无法测量的 3D/栅格内部文字明确 unassessed，不能当已核。

对于由本程序实际生成的位图，`figure_spec` 可保存全部 live-artist 文字与字号，并重新渲染比对交付 PNG 的实际像素。只有这条证据当前有效、原图身份与最终 DOCX/PDF 位置均匹配时，才能按实际安置比例换算字号；单独提供矢量源 PDF 或手填字号都不够。位图中另含无法测量的图像文字时仍不走此放行路径。

`manuscript compose --docx ... --pdf ...` 可从注册块直接组装、真实引擎导出并核对实际 DOCX/PDF。章节与字数默认不设硬限制，可用 outline 和 required-sections 自订；额外附录不会被丢掉。数字必须指向当前已校核模型或已复核数据格/实际聚合，并声明必要的格式、百分比和缺失规则。仅有一个任意的 trace 字段不算溯源。表头重复、行不拆、图与图注相连有实际 OOXML 设置。

表格必须为完整矩形；已注册表要通过当前全表 final，其他结果表的数值格要逐格提供真实 trace。打印后的表格、图注和表题会重新对账，不能以正文通过替代。Word 压缩图片时，导出器核对原图确实存在于当前 DOCX、PDF 图注位置唯一且几何匹配，再回填原图并重新终检；失败保留旧完整 PDF，不拿旧文件冒充新导出。标题保持黑色并去掉模板自带装饰边框，章节标题随正文跨页。

Agent 仍须完成论文问题、方法理由、连贯结果解释、讨论、局限、引用与必要附录；组装器不会自动产生可靠理论叙事。分析报告和全模型/全图集目录另外交付。最终图在 DOCX/PDF 的真实宽高、dpi、字号、哈希和图注需 `layout_check` 重新核对，再实际逐页查看。源图 600 dpi 不能证明最终缩图字号合格。

## 发布与维护验收

`release` 重读当前 final、全材料覆盖、模型执行/校核/方法评估、论断语境复核、实际成稿和安置证据。论文范围要求实际 PDF；省略已注册图或章节不能冒充全项目 complete。limited 只表示明确缩小的范围，范围内仍须通过全部事实硬条件。failed/unassessed/cancelled/timeout 真实保留。

发布评估只读，并在前后比较证据封存；评估过程中原件、结果、代码或账本变化即失败。评估沿正文/论断/图自动补齐依赖模型和数据，显式写空 models 不能隐藏这些依赖。`release show` 重新判断当前发布依据；重新拟合或更新后，即使新结果再次通过，也须重建发布以绑定新版本。所有失败的硬条件均进入 hard_failed。

阶段范围记录 `deliverable_type=datasets/models/figures/manuscript`。完整研究范围明确为 `full_research`，包含实际 DOCX/PDF、论文块及 `analysis_report`，且全部条件通过时才有 `project_ready=true`。报告文件存在不代表理论叙事已被机器验证，Agent 仍须检查全部事实论断、方法、引用及解释。

API 字段位置：`evaluate/build` 直接返回 `project_ready`；`show/current` 的当前门检位于 `evaluation`，读取 `evaluation.project_ready`。没有发布或评估失败而缺此对象时按未就绪处理；不能把退出码 0 或根层 status=complete 当成完整研究就绪。

缓存分别核对实际实现文件、规则、输入、输出和运行环境；依赖步骤在写入前检查重复 ID、未知父节点与环。同一版本同一运行重复引用缓存保持幂等，复用仍不冒充重新执行。额外实现依赖及包版本需要在自选适配器中完整声明。

外部命令保留原始 stdout/stderr 字节及哈希，JSON 重复键或非有限常量拒绝。命令必须是明确选择的可信分析程序，并以前台进程结束工作；现有保护不是恶意程序的操作系统沙箱，也不承诺自动管理脱离父进程的后台任务。

事务使用项目发布锁、父版本检查、代码与输入绑定；不同输出合并保留，同一父输出的竞争修改明确冲突。发布指针最后原子替换，半写不能指向正式版。锁以 owner token 释放，不能靠时间较长就抢走仍活着的本地进程锁。普通读取也校验契约、账本完整性与必需特性，损坏记录明确拒绝。

维护时使用仓库 `tools/run_acceptance.py` 运行真实测试，保留每项结果、原始日志、环境、执行前后源码/fixture 哈希和事先冻结的场景映射。`acceptance_cards` 不接受仅测试源码、自填 passed 或 skip 当集成通过。测试证明的是实测样本和环境；历史上是否先期望后实现不能靠事后补时间戳证明。
