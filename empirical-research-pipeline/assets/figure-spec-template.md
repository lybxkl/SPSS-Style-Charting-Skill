# 图表规格与图注

## 制图规范

| 项目 | 设定 |
|---|---|
| 物理宽度 | 15.0 cm |
| 字体 | 中文宋体；西文 Times New Roman |
| 字号 | 轴标签/图例 7.2–8.5 pt |
| 分辨率 | PNG/TIFF 600 dpi |
| 矢量 | PDF，字体 Type 42 嵌入 |
| 图内标题 | 无 |
| 误差线 | 95% CI（Wilson） |
| 颜色（可自选） | 按数据含义选择，推荐保持跨图语义清楚；注明实际取色/色标与辅助编码，不限定色卡或类别数 |

## 图清单

| 图号 | 文件名 | 内容 | 数据来源 | N | 放置 |
|---|---|---|---:|---|---|
| 图 1 | `fig1_*.png` |  |  |  | 正文 |
| 图 2 | `fig2_*.png` |  |  |  | 正文 |
| 附图 1 | `figS1_*.png` |  |  |  | 附录 |

## 图注模板

```text
图 X  [图题，说明“是什么”]
注：[点/线/误差线/颜色定义]；[样本范围与 N]；[变量编码说明]；[数据来源]。
```

## 图注自检

- [ ] 图号与正文引用一致
- [ ] N 与数据/表/正文一致
- [ ] 误差线定义写明
- [ ] 参照组写明
- [ ] 数据来源写明
- [ ] 没有在图注里下因果结论
