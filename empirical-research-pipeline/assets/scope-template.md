## 8. 机读范围白名单（scope.json，供 scope_conformance.py 核对）

为每个决定范围的分类列声明纳入值；任何学科通用，引擎不内置类别词。分析表实际分布对照此白名单，范围外命名类别 n>0 即报错。

```json
{
  "columns": {
    "<分类列名>": {"include": ["<纳入值1>", "<纳入值2>"], "label": "<该列含义>"}
  },
  "min_cell_n": 20,
  "temporal": [
    {"col": "<日期列>", "min": "2021-01-01", "max": "2021-12-31"}
  ],
  "intervals": [
    {"key": "<主键列>", "start": "<生效起列>", "end": "<生效止列>"}
  ]
}
```

- 每个数据集一份；多数据集各自声明各自的分类列。
- `min_cell_n` 用于率表/热图小样本单元格警告（`--cell-cols`）。
- 缺失值如何处理在此声明（纳入白名单写 `(NA)` 或按排除处理）。
- `temporal`/`intervals` 可选但强烈建议：分类白名单核不出日期越界或同一主键生效区间重叠（SCD/拉链）。声明后 `scope_conformance.py` 与零信任审计器自动机器核（references/10 §19）。业务状态转移合法性属领域逻辑，写项目剖面，不写死引擎。
